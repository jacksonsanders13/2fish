# 2fish

AI growth consultant for small local businesses. This is the Phase 1 UI mockup: front-end only, fake data, no backend.

## Run it

```
npm install
npm run dev
```

Open http://localhost:3000. The index page links to both visual directions (`/a` and `/b`) and every mock screen.

Design decisions are in `DESIGN.md`. Project rules are in `CLAUDE.md`.
